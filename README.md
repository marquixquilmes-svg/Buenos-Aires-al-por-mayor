# Buenos Aires al por mayor

V1 comercial — base inicial del proyecto.

## Objetivo
Construir una aplicación web comercial con catálogo, productos, carrito, checkout, cuentas de usuario y una arquitectura preparada para despliegue.

## Seguridad
- No se almacenan secretos en el repositorio.
- Las credenciales y API keys deberán configurarse mediante variables de entorno/secrets.
- La autenticación se implementará con sesiones/tokens seguros y cookies protegidas cuando corresponda.

## Estado
V1 — estructura inicial.
